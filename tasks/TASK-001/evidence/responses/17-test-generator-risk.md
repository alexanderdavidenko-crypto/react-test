## Покрытие пунктов 1–7
1. **shared/api (раздел 8, п. 1–6) — покрыт.**
   - HTML 200/201, валидный JSON с неожиданным статусом, `HttpResponse.error()` проверены для всех четырёх функций клиента.
   - 400 и 500 с контрактным телом дают `ApiError` с `code` и `fieldErrors`. Не-2xx без контрактного тела (HTML, пустое тело, JSON без `error`, не-строковое сообщение, `null`) дают `ResponseShapeError` со статусом.
   - Неверная форма 200 (неизвестный enum, не-ISO дата, невозможная дата, нет `meta` и другие случаи) дают `ResponseShapeError`. Есть контрольный тест: валидное тело с лишним полем проходит.
